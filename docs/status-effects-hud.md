# Status effects HUD

The camera's existing UI CanvasLayer owns `scenes/ui/status-effects/status-effects-hud.tscn`. The row anchors 24 px from the left and 18 px from the bottom. Eight cached 34 px icons have 5 px spacing; further groups use `+N`. Empty, dead, paused, phone-open, quest-offer and dialogue states hide the row. The repertoire remains at the bottom-right, and the Incantation Assistant is unchanged.

`StatusEffectsHUD` binds only `Player_Manager.get_local_player().hitbox.effects`. Manager changes refresh the row immediately. A 10 Hz presentation update reads remaining times from `ActiveEffectManager.get_entries()` and detects replacement players. There is no independent duration countdown. Connections are disconnected on rebinding and tree exit. Nodes are reused; no icon reconstruction occurs during ticks.

`get_entries()` returns deeply detached containers, preserving each independent stack. The older key-only `snapshot()` remains available to compatibility callers and is not used for HUD counts. Groups combine key and beneficial classification, counting actual entries. Their duration indicator shows the longest remaining stack relative to the longest authored duration. Expired stacks disappear individually. Debuffs sort first, with stun, silence and periodic damage ahead of lesser effects; priority and key give deterministic ordering.

`status-presentation.gd` contains names, descriptions, original line-glyph choices and priorities. To add a presentation, add a key and a glyph mapping; unknown keys already get a named fallback. Add new glyph shapes to `status-effect-icon.gd`. Buffs use an upper arc and muted teal accent, debuffs a warning chevron and muted rose accent. Glyphs, classification marks and text tooltips provide distinctions beyond color. Icons accept keyboard focus and expose their tooltip description through Godot's Control accessibility support.

Healing-over-time is now correctly marked beneficial in both direct `HealEffect` application and `HitboxComponent.apply_status()`. ModifyStat effects retain their existing beneficial classification. Refresh replaces classification alongside source/data. Selective clear now removes matching entries rather than removing all stacks sharing their key; regression coverage includes opposite-classification stacks with the same key. Durations, resistance, periodic timing and stack policies retain gameplay authority in ActiveEffectManager. Enemy world-space feedback remains; redundant local-player status dots are hidden.

Ordinary load/checkpoint restoration clears all temporary effects. The row follows the newly spawned player's authoritative manager. See [verification and captures](combat-save-v1-verification.md).
