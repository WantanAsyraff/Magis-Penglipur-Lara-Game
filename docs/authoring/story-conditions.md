# Story conditions

Create a condition Resource and evaluate through `StoryDirector.evaluate_condition`. Available types: `StoryFlagCondition` (registered definition and comparison), `StoryStageCondition`, `StoryChapterCondition`, `StoryQuestCondition` (offered, active, objectives complete, handed in), `StoryCutsceneCondition` (existing CutsceneSequence), `StorySubjectCondition` (`subject_id`), `StorySpellCondition` (`spell`), `StoryItemCondition` (`item`, `minimum_quantity`), `StoryChoiceCondition` (`choice`, `option_id`), `StoryAllCondition`, `StoryAnyCondition`, and `StoryNotCondition`. For a quest prerequisite, select a registered quest ID and `HANDED_IN` when the reward must be claimed. For a cutscene fact, assign the existing sequence Resource; both natural and skipped completion use its canonical flag. Empty composition, missing children, cycles and excessive depth fail closed. Conditions only read facts. New condition classes should extend `StoryCondition` and implement `validate` and read-only `evaluate`.
