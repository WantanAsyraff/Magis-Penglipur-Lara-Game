# Story transitions

Select a StoryStageData Resource, add a StoryTransitionData to `transitions`, assign stable lowercase `transition_id` and registered `target_stage_id`, and add StoryCondition Resources. Set `priority` for deterministic selection. `automatic` evaluates on accepted events and flag changes; manual transitions require `StoryDirector.request_transition(id)`. For an event requiring arrival during the current stage, set `required_event_type` and `required_event_target`. `once_only` records a receipt in the campaign story section after a successful save. Use `StoryDirector.get_diagnostics()` for blocked reasons. Production prologue stages remain transition-free until verified story triggers are authored; use `tests/story/story-transitions.tscn` as the isolated execution demonstration.
