# Content troubleshooting

Inspect the actual definition and Remote Inspector before changing shared controllers. This table gives the symptom, likely cause, verification, supported fix and source boundary. Relevant authoring guides describe exact Editor steps.

| Symptom | Likely cause | Verify | Fix | Relevant files |
| --- | --- | --- | --- | --- |
| New spell absent | Not learned/equipped, missing manifest, nested file outside scan | Check Spell_Library.all_spells then Player_Global_Data learned/equipped lists | Bake top-level player spell, link subject, purchase and equip; do not grant entire library | autoloads/spell-library.gd; authoring/spells.md |
| Works in Editor, missing in PCK | Editor-only discovery hid absent preload | Compare SPELLS entry and fresh exported dependency | Run actual spell baker; retain scene/effect refs; rebuild pack | tools/bake-spell-manifest.gd; spell-manifest.gd |
| Invalid/duplicate incantation | Wrong case/direction, empty sequence or exact duplicate | Run library validator; inspect equipped resolver validation_errors | Use lowercase four directions, unique exact combo; keep intentional proper prefixes | incantation-resolver.gd; spell-validator.gd |
| Shared prefix casts “early” | CHAINED is working as designed | Trace Strike → Resonate → Shatterwave independent completions | Continue the exact branch; select another strategy only as an explicit design change | Player.incantation_strategy; authoring/spells.md |
| Correct input burst but no spell | Execution fails cost/cooldown/target after valid acceptance | Inspect casting request status/reason, mana and cooldown | Correct execution conditions; do not tie valid-input feedback to cast success | spell-casting-component.gd; player.gd |
| New field not visible | Field unreferenced or no course UI route | Inspect course academic_fields and SpellTreeView.course_data | Reference field/course/subjects and expose a course-view scene | authoring/fields.md; courses-and-subjects.md |
| Subject cannot be purchased | Prerequisites, comprehension, XP, duplicate completion or invalid course | can_purchase_subject and AcademicValidator errors | Use completed subject IDs, award intended ranks deliberately, fix graph/refs | player-data.gd; academic-validator.gd |
| New course purchase prevents saving | Missing GameSaveSchema.COURSES registration | Compare completed subject ID with allowlisted courses | Register actual course Resource; do not bypass save validation | components/save/game-save-schema.gd |
| Spell effect does nothing | Wrong target accepts contract, dormant field or explicit effects replace legacy flags | Inspect executor effect.validate/accepts and LegacySpellAdapter | Use compatible hitbox/target and real typed payload; implement genuinely new handler | spell-executor.gd; authoring/spell-effects.md |
| Status exists but no mechanic | Unhandled status key / marker without consumer | Search actor/hitbox periodic/query handlers | Compose Conditional/Chain marker behavior or implement tested handler | hitbox-component.gd; active-effect-manager.gd |
| Status icon “missing” | No local effect, hidden modal/death state, or overflow | Inspect local player's effects.get_entries and HUD grouped_entries | Correct application/beneficial metadata; close modal; inspect overflow; add presentation definition only for visuals | status-effects-hud.gd; status-presentation.gd |
| Enemy cannot detect player | Wrong groups/faction, terrain occlusion/range or client authority | Detection.blackboard/target_groups/relations and masks | Correct perception/team settings and actual scene groups; run authoritative session | enemy-detection.gd; enemy-perception-data.gd |
| Enemy never attacks | No compatible action/loadout, too little mana or range/LOS failure | AI scores, selected action, available_abilities and can_use result | Match action kind/role and reachable range; configure mana and timings | enemy-ai-controller.gd; enemy-combat.gd |
| Enemy “has no abilities” | Empty EnemyData.abilities, wrong SpawnData override, legacy adapter choice | Remote enemy.definition, combat.loadout and root enemy_data | Assign actual definition before ready and add typed abilities; no global spell auto-grant | enemy.gd; enemy-spawner.gd |
| Enemy stops outside melee reach | Root distance/collider mismatch or unsuitable custom movement | Compare max_range and physical separation, pure-melee band | Author adequate reach/body/probe geometry; test movement instead of copying controller | enemy-movement-component.gd; enemy-ai-controller.gd |
| Defensive/support action unused | Role/payload mismatch or full health recipient | ability_for action filter, target_for and recipient HP < .8 | Assign DEFENSE/HEAL role and compatible SELF/ALLIES spell/action | authoring/enemy-abilities.md |
| Boss phase appears stuck | Incorrect thresholds/order, empty eligible pool, disabled combat, missing animation or interruption recovery | Inspect current_phase_index/state/timers/attack epoch and actual range | Fix phase refs/ordered thresholds/pools; do not restart stale await callbacks | boss.gd; boss-phase.gd |
| Boss warning differs from hit | Wrong kind-specific dimensions/timing, moved origin or projectile assumption | Compare telegraph fields to melee/arc/dash/AoE code | Use the same configured radius/arc and proper aoe_warning_duration; visually test wall-clipped dash | boss-telegraph.gd; authoring/bosses.md |
| Item not acquired | Pickup gate/owner/authority, null loot, full stack/capacity or replayed receipt | DroppedItem quantity/loot_data and Inventory_Manager accepted count | Fix source/ref/capacity; publish only accepted quantity; don't add overlap rewards | dropped-item.gd; inventory-manager.gd |
| Loot never drops | chance 0, invalid entry or not attached to actual definition | EnemyData.loot, LootData.validate and death once-only path | Use a temporary deterministic test roll, register item, attach actual loot then restore intended chance | enemy-loot-component.gd; authoring/items-and-loot.md |
| Recipe unavailable/cannot craft | Output missing from room list, wrong inputs/qty or output capacity | Crafting_Context.available_recipes and _craft_plan result | Assign output ItemData recipe and valid positive inputs; register all items | crafting-room.gd; crafting-ui.gd |
| Quest objective not progressing | Not explicitly accepted, wrong target/owner/type, prerequisite order, spawn not acquisition | QuestInstance status/progress, seen_events and evaluator event | Correct real publisher integration/IDs, obtain actual items, accept explicitly | quest-objective-evaluator.gd; quest-event-hooks.gd |
| Quest unknown in board/save | Database assigned only to board or unknown referenced item/enemy | QuestManager.registry.quests/errors and database constructor list | Use loaded DB array or add new DB path to registry; register dependencies first | quest-registry.gd; authoring/quests.md |
| NPC offer absent | Ineligible faculty/prereqs, cooldown, wrong focus/LOS or another dialogue/card | Component instance/indicator, live_offers, detection focus and accessibility | Correct identity/faculty, clear modal and provide grounded approach; no auto-accept callback | quest-npc-component.gd; detection-component.gd |
| Wrong portrait/contact | NPC ID confused with dialogue_identity or missing presentation manifest | NPCPresentation.resolve and timeline portrait branches | Register/assign matching identity and compatible character/asset | npc-presentation.gd; presentation/manifest.gd |
| Room ID not found | SceneData outside hub scan, duplicate ID or stale bake | Scene_Registry.scenes and World_Manifest output | Move SceneData to hub structure, set explicit new ID and run hyphenated world baker | scene-registry.gd; bake-world-manifest.gd |
| Wrong spawn / two players | Missing override/PlayerSpawn or manually placed Player plus ZoneRoot | Pending next_spawn_marker, final position, actual Player instances | Add clear body-center markers, remove redundant Player; test actual transition | zone-root.gd; player-manager.gd |
| Save disabled in a room | UI/training root, dead/uninitialized player, network peer, dialogue/reward transaction | SaveManager.unavailable_reason | Return to supported campaign ZoneRoot, finish transient operation; don't bypass authority | save-manager.gd |
| Save fails after content rename/removal | Registered spell/item/quest/subject/scene ID cannot resolve | GameSaveSchema.stage/QuestSaveService.stage and missing reference | Restore compatible ID or implement explicit version/content migration; never silently drop claims/items | architecture/save-load-architecture.md |
| Damaged/incompatible save | Bad envelope/checksum/version/bounded values, not a legal migration | Load metadata status and explicit backup validation | Load backup explicitly; preserve damaged evidence, choose safe other slot; no silent reset | game-save-store.gd; save-system-v1.md |
| Broken UID / import parse failure | Missing/moved asset, stale ext_resource path, syntax error or wrong engine | First Output error, actual FileSystem path and project.godot features | Use Godot 4.7 import; restore/move asset correctly, fix source/reference; don't fabricate a new released UID | developer-workflow.md; identifiers-and-conventions.md |
| No custom class in New Resource | Script import/parse failure or Node mistaken for Resource | Source class_name/extends and Output | Fix compilation, select exact Resource class (subjectData casing); use scenes for Node components | reference/resource-reference.md |
| Tutorial never opens | Invocation path missing, has_tutorial false, empty data or quest-route mismatch | TutorialComponent setup and nonquest dialogue callback | Assign real data/panel, use actual try_show integration, test Close/Escape restores control | authoring/tutorials.md |

Paths abbreviated in the last column are resolved by their canonical guide and [registration/property reference](content-registration-matrix.md). See the [audit findings](../documentation-audit.md) for code defects and unsupported extension points deliberately not changed by this documentation task.
