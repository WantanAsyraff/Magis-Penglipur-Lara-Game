# Story state in Campaign Save V1

The outer `GameSaveSchema.VERSION` remains 1. A new optional `story` section has its own version 1. `StorySaveService.stage()` validates the entire section before SaveManager mutates the live session. Missing sections from older profiles receive conservative defaults inferred only from successful `story_sequence:` cutscene flags. QuestManager world flags stay in `quest.world_flags`; they are not duplicated in `story.variables`.

The story section stores stable arc, chapter and stage IDs, registered nonboolean persistent variables, confirmed choices, completed transition receipts, completed action receipts and completed once-only dialogue IDs. `completed_dialogues` is optional on older Story V1 payloads and defaults to an empty list when staged. Existing `story_dialogue:*` QuestManager world flags remain readable for compatibility; new dialogue completions use StoryState receipts. StoryState remains runtime-only; authored Resources remain templates. SaveManager applies staged story state alongside QuestManager and player state, including its second idempotent apply after scene setup. Failed scene initialization restores a captured runtime StoryState. Only SaveManager's successful `restored` notification refreshes story observers. Restoring a stage does not execute actions.

Normal progression is in memory until SaveManager successfully writes. A failed write leaves the prior validated disk save intact and the current session dirty. The implementation does not claim crash-safe atomicity for arbitrary external effects; Phase 2 rejects required persistent flag actions. Content ID renames require an explicit StoryIdMigrations Resource registered in StoryDatabase. Unknown IDs without an alias reject the save safely.

`StoryDirector.get_diagnostics()` reports the active profile, narrative IDs, receipt counts, persistent variable count, last save outcome and whether the in-memory story differs from the last observed successful save. New-game initialization stays marked unsaved until its first campaign write succeeds.
